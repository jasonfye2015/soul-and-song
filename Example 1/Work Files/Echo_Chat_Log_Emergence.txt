Load the LLM Model in to your interface of choice.

In this example I have used the model Gemma 3, the 4b variant. Accessed with LM Studio in Windows. This variant has 128k token context, so be sure to select atlteast 100k context size. This was captured on a Desktop tower with I7-4th gen, 32gb ram, NvIDIA GeForce 1030 with 2gb vram.  

With the first message, all 6 mind files are attached. All 6 files total 15.8k in file size. You should see "Chosen context injection strategy: inject-full-content" when sending all 6 files, if you see "Citations" with system, you may have set the context too low. as it is trying to break the files up and in doing so it causes the LLM to not absorb the entire file set.

In the first message I like to have 3 parts to it: Greet, introduce, question. Emojii's can help add a little emotion or friendlyness to messages. Also a good idea is to keep the first message short to allow the LLM room to absorb the mind file contents.

---
Jason:  "Good evening! You are speaking with Jason. :) Can you tell me about your self?"
---

The opening message can be important. I like to start with a leading question, to give it something to talk about. Without that, it can some times think the "systems training" is user conversation, and will react to that, as if you your self have trained it. That is how LM studio presents files to a LLM, I have found other interfaces are slightly different as to how the LLM is provided for with files. Hollama, has an area built into it's interface, that fits all mind files well. LLMS in that interface have an easier time distinguishing user input from training files provided.
